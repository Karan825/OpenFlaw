SYSTEM ARCHITECTURE

Engineered for Deterministic Safety

OpenFlaw isolates every execution in disposable cloud microVMs with cryptographic validation and automated test gates.

01
INGESTION

FastAPI Webhook Receiver

Validates HMAC SHA-256 signature headers from GitHub. Parses issue labels like @agent fix and dispatches workflow dispatch events to the control repo.

HMAC-SHA256 Render / Cloudflare
02
EXECUTION

GitHub Actions Orchestrator

Boots standard GitHub runner environment on-demand. Obtains short-lived GitHub App installation tokens to authorize branch pushes and PR creation.

GitHub Actions App Auth PEM
03
ISOLATION

E2B MicroVM Sandboxing

Instantiates a clean, isolated Firecracker-based Ubuntu microVM. Target repositories are cloned inside the VM without exposing control runner secrets.

e2b-sandbox Firecracker MicroVM
04
REASONING

ReAct Engine & AST Graph

Tree-sitter maps symbols and code hierarchy. Gemini 2.5 Flash executes autonomous Thought-Action-Observation cycles using custom regex search and file editor tools.

Gemini 2.5 Flash Tree-Sitter AST
05
SECURITY

Safety Guard & Diff Guard

Validates all proposed edits before execution. Rejects unauthorized file modifications outside repo scope, prevents secret leaks, and limits total diff size.

Diff Guardian Path Normalization
06
VERIFICATION

Pytest Gate & PR Delivery

Executes target test suites inside the E2B sandbox. If tests fail, the ReAct loop self-corrects. When passing, creates a clean branch and submits the PR.

Pytest Coverage Automated PR

DEPLOYMENT GUIDE

Deploy OpenFlaw in 3 Minutes

Configure your repository secrets and spin up the webhook receiver on Render or your local machine.

.env configuration 
# LLM Configuration
LLM_PROVIDER=gemini
LLM_MODEL=gemini-2.5-flash
GEMINI_API_KEY=AIzaSyD_your_google_ai_studio_key

# E2B Sandbox Configuration
E2B_API_KEY=e2b_your_sandbox_api_key

# GitHub App Integration
GITHUB_APP_ID=123456
GITHUB_INSTALLATION_ID=789012
GITHUB_PRIVATE_KEY_PATH=./github-app-key.pem
WEBHOOK_SECRET=your_hmac_webhook_secret_key
Run Local Benchmark Suite

.github/workflows/agent-worker.yml 
name: OpenFlaw Agent Worker

on:
  workflow_dispatch:
    inputs:
      repo: { description: 'Target repo (owner/name)', required: true }
      issue_number: { description: 'Target issue number', required: true }
      issue_body: { description: 'Issue description context', required: true }

jobs:
  run-agent:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout OpenFlaw Worker
        uses: actions/checkout@v4

      - name: Setup Python 3.11
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install Agent Dependencies
        run: pip install -r worker/requirements.txt

      - name: Execute Autonomous Agent Loop
        env:
          E2B_API_KEY: ${{ secrets.E2B_API_KEY }}
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
          APP_ID: ${{ secrets.APP_ID }}
          INSTALLATION_ID: ${{ secrets.INSTALLATION_ID }}
          APP_PRIVATE_KEY: ${{ secrets.APP_PRIVATE_KEY }}
        run: |
          python worker/src/main.py \
            --repo "${{ github.event.inputs.repo }}" \
            --issue-number "${{ github.event.inputs.issue_number }}" \
            --issue-body "${{ github.event.inputs.issue_body }}"
